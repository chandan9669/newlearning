# 4-Month Learning Plan (21 hrs/week ≈ 3 hrs/day, ~336 hrs total)

**Learner:** Senior Salesforce Developer (Sales/Service/Marketing/Data Cloud)
**Path:** A (SF QA Automation) → B (Python SWE / DSA / System Design) → C (AI foundation) → Robotics (on-ramp only, last)
**Constraints:** Free resources only · English or Hindi · Build-first (build > read > watch)
**Core rule:** START INTERVIEWING IN MONTH 1. Your Salesforce QA edge is strongest now. A QA Automation offer pays you to keep climbing.

> Honest expectation-setting for 4 months:
> - Stage A → genuinely interview-ready & hireable.
> - Stage B → interview-CAPABLE for junior/mid Python SWE (not senior-strong; DSA mastery alone takes 4-6 months).
> - Stage C (AI) → solid foundation + 1 portfolio project (not yet AI-engineer interview-ready).
> - Robotics → parked; on-ramp taste only.

---

## Month 1 — Stage A core + START interviewing
Goal: building tests daily; applying to jobs by week 3.

- Week 1: PYTHON FOUNDATIONS FIRST. Automate the Boring Stuff (or CS50P, or CodeWithHarry in Hindi - pick ONE). Coming from Apex, move fast: focus on Pythonic idioms (list comprehensions, dicts, functions, exceptions, OOP, context managers). Type every example. In parallel, spin up a SF Developer Edition org and start the Trailhead Provar module.
- Week 2: Finish Python foundation + pytest deep (fixtures, parametrize, Page Object Model) + Selenium/SeleniumBase. Clone QA Playground repo; automate 10 tricky elements (shadow DOM, iframes, dynamic waits). Write your first 5 pytest tests against the SF org.
- Week 3: Start 30-Day SDET Challenge repo (move fast, ~2 wks) AND begin applying + interviewing. Treat interviews as practice.
- Week 4: Build ONE portfolio project — a real test suite against a SF org, public GitHub, with README. This is your interview centerpiece.

Weekly split: ~15 hrs building · ~4 hrs interview Q&A (himanshuai senior set) · ~2 hrs Hindi/video fallback if stuck.

## Month 2 — Stage A polish + Stage B begins (Python + DSA)
Goal: keep interviewing for QA; start SWE foundation underneath.

- Keep applying/interviewing for QA Automation. Take the offer if it comes — keep climbing on their payroll.
- Start NeetCode roadmap: PATTERNS not random grinding. ~2/week: arrays/hashing, two pointers, sliding window, stack, binary search.
- Use Grind 75 to schedule which problems.

Weekly split: ~10 hrs DSA · ~6 hrs QA portfolio/interview upkeep · ~5 hrs Python fluency.

## Month 3 — Stage B core (DSA + System Design)
Goal: become interview-capable for Python SWE.

- NeetCode: trees, heaps, graphs, dynamic programming (hard but high-value).
- Begin System Design Primer (donnemartin). Your SF integration/limits experience makes this click faster. ~4 hrs/wk read + Anki.
- Do 2-3 free mock coding interviews.

Weekly split: ~13 hrs DSA · ~5 hrs system design · ~3 hrs mocks.

## Month 4 — Stage C (AI foundation) + robotics taste
Goal: credible AI start + 1 AI portfolio project. Robotics = on-ramp only.

- Weeks 1-2: Karpathy Zero-to-Hero — build a neural net + mini-GPT from scratch (build-first anchor).
- Week 3: fast.ai lessons 1-3 (train a working model, top-down) OR start Hugging Face LLM course — pick by energy.
- Week 4: Build ONE small AI project (RAG bot over your own notes, or fine-tune a small model). Put on GitHub.
- Robotics: if curious, spend 2-3 total hrs skimming Modern Robotics intro + free textbook Ch. 2 to decide LATER if it deserves a dedicated future block. Do NOT start ROS 2 now.
